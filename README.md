<h1 align="center">Seedmux</h1>

<p align="center"><strong>English</strong> · <a href="#简体中文">简体中文</a> · <a href="#繁體中文">繁體中文</a></p>

Seedmux is a Windows terminal for working with AI coding agents. Each tab shows what its agent is doing and whether it is waiting on you, so several agents can run side by side without constant checking. It works with local shells, WSL, and remote hosts.

This is a trial build: it is free to use for evaluation, and some features are still rough.

## Install

1. Download `SeedmuxSetup.exe` from [Releases](https://github.com/NNIIYYYX/seedmux-windows/releases/latest).
2. Run it. It installs for your user without administrator rights and updates an earlier install in place.
3. The installer is not code-signed yet, so Windows SmartScreen may warn first: choose **More info › Run anyway**.

To uninstall, use Settings › Apps or run `SeedmuxUninstall.exe` from the same release. Your settings are kept.

## Requirements

- Windows 10 (build 17763 or later) or Windows 11, x64
- WSL2, if you want to use WSL

卸载：在“设置 › 应用”中卸载，或运行同一版本里的 `SeedmuxUninstall.exe`。你的设置会保留。
